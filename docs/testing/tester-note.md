# Spaced Positions — Tester Note

## What is this?

Spaced Positions is a free chess training program. It helps you remember chess puzzles using **spaced repetition** —
the same principle that makes flashcard apps effective. The program shows you puzzles just before you'd forget them,
so you learn faster and retain more.

You are helping us test the program before it is released to the public. Your feedback will shape what the program
becomes. This note explains what to expect, how to install it, and how to give feedback.

## What it costs you

- **About 15 minutes a day** of training, for 4–6 weeks
- **Three short surveys** (2 minutes each): one per week and one at the end
- **One 20-minute conversation** at the end (by video call, if you agree)
- Everything stays on your computer. Nothing is sent anywhere without your permission.

## Installing

Follow the instructions in the program's README file. In short:

1. Download the program for your operating system (macOS or Windows)
2. Install it (double-click the installer, or run one command in a terminal)
3. Start the program — it opens in your web browser

If you get stuck, write down where and ask the maintainer for help.

## Your first session

When you start the program for the first time, do these four things:

1. **Get it running.** The program should open in your browser and show a welcome screen.
2. **Switch to your language.** Go to Settings and change the language to German, French, or Italian if you prefer.
3. **Load the starter pack.** The program offers a set of puzzles on the first screen — load it and solve your first puzzle.
4. **Try the help.** Press `?` in any screen to see what the keys and buttons do.

After each step, ask yourself: *How easy was this?* (1 = very hard, 7 = very easy). Your answer helps us.

## Training

After the first session, train daily. The program's main mode is called **Review** — it shows you puzzles at the right
time. Just open the program and start solving.

During the first two weeks, we also ask you to try these tasks:

- **Enter diagrams from a book.** Open the Collect mode and enter about 10 chess positions from one of your books.
- **Make a puzzle from a game.** Open Analyse, load one of your games, and turn a moment into a puzzle.
- **Find unfinished work.** In the Library, look for positions from your book that still need a solution.

## Giving feedback

You can give feedback at any time. Three ways:

1. **The feedback form.** In the program, type `:feedback` in the command line. It opens a short form with your
   version and mode already filled in. Use it for "this confused me", "this broke", or "I wish…".
2. **A chat group.** If you prefer, you can write in a shared chat.
3. **The surveys.** You'll receive three short questionnaires by email.

Be honest. If something feels wrong, slow, or confusing — tell us. We need to know what doesn't work.

## The usage report

The program can write a file that shows how you used it: how many puzzles you solved, which commands you used,
and how long you trained. **This report contains no chess positions, no names, no comments — only numbers.**

To write it:

1. Go to Settings, find the Data section, and click "Usage report"
2. Or type `:test-report` in the command line
3. The file downloads to your computer. Look at it — it's a plain text file
4. If you're comfortable sharing it, send it to the maintainer

**You decide whether to send it.** The program never sends anything on its own.

## What the app never collects

- No chess positions, FENs, or moves
- No names, comments, tags, or notes
- No personal data (your name, email, address)
- No telemetry — the program sends nothing to any server
- No usage tracking — the usage report is written only when you ask for it

Everything stays on your computer.

## Questions?

Contact the maintainer. There are no wrong answers — we're here to learn from your experience.
