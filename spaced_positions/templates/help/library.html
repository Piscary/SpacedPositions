{% translate "Search" %}
{% blocktranslate trimmed %}{{ slash }}, type, {{ enter }} to the results. {{ search_help }} explains the search language.{% endblocktranslate %}
{% translate "Remove a filter" %}
{% blocktranslate trimmed %}{{ unfilter }} takes the last term out, {{ clear }} clears the search (also the ✕ in the bar). The filter pane shows every term, each with a way out.{% endblocktranslate %}
{% translate "Switch the collection" %}
{% blocktranslate trimmed %}{{ one }} positions … {{ six }} tags, or click the tabs. {{ enter }} on a player, a source or a tag shows its positions or games.{% endblocktranslate %}
{% translate "Select" %}
{% blocktranslate trimmed %}{{ select }} selects a row, {{ visual }} a range as you move. Without a selection, a command acts on everything the search found.{% endblocktranslate %}
{% translate "Work on them" %}
{% blocktranslate trimmed %}{{ tag }} tag, {{ train }} train, {{ analyse }} analyse one after the other, {{ export }} export as PGN or puzzle pack, {{ trash }} to the trash.{% endblocktranslate %}
{% translate "Look at one" %}
{% blocktranslate trimmed %}{{ enter }} opens it in Analyse, {{ beside }} beside the list. The board of the same link group follows the cursor, and so does a Moves pane.{% endblocktranslate %}
{% translate "Order and groups" %}
{% blocktranslate trimmed %}{{ sort }} sorts by a column (again: reversed). Sorted by source or difficulty, the rows come in groups: {{ fold }} folds one. {{ display }} switches between table, list and grid.{% endblocktranslate %}
